继承允许我们有一个相互关联的类的层次结构，允许我们有一个包含公共功能的基类，允许从那个基类中分离出来，从最初的父类中创建子类，
其实主要还是避免代码重复
```
#include <iostream>

class Entity {
public:
    float X, Y;
    Entity(float xa, float ya) : X(xa), Y(ya) {}
    void move(float xa, float ya) {
        X += xa;
        Y += ya;
    }
};

class Player : public Entity {
public:
    Player() : Entity(3, 6), Name("FALLING") {}
    const char* Name;
    void PrintName() {
        std::cout << Name << std::endl;
    }
};

int main() {
    Entity e(1, 5);
    Player x;
    x.PrintName();
    std::cout << x.X << " " << x.Y << std::endl;
    return 0;
}
```
Player类型不只是Player类型，而且也是一个Entity，可以在任何我们想要使用Entity
的地方使用 Player。
感觉有点像继承了父亲一切那种感觉。

# 继承的主要原理包括：

代码重用：派生类继承基类的所有公有和受保护的成员（属性和方法），从而可以重用基类的代码。
多态性：通过继承，派生类可以重写基类的方法，提供不同的实现。这种机制称为多态性。
层次结构：继承建立了类之间的层次结构，促进了代码的组织和管理。
继承的类型
# C++ 支持以下几种类型的继承：

公有继承（public inheritance）：基类的公有和受保护成员在派生类中保持其访问权限。
保护继承（protected inheritance）：基类的公有和受保护成员在派生类中变为受保护成员。
私有继承（private inheritance）：基类的公有和受保护成员在派生类中变为私有成员。

个人感觉，就像粘贴和适量修改

# 代码重用：

通过继承，派生类可以直接使用基类中已经实现的功能，而不需要重新编写这些功能。这就像是“粘贴”基类的代码到派生类中。
继承允许派生类增加或修改基类的功能，而无需修改基类本身。
代码维护和扩展：

当基类的实现需要修改时，所有继承该基类的派生类会自动继承这些修改。这使得代码维护变得更容易。
派生类可以添加新的方法和属性，或重写基类的方法来扩展功能，这就是所谓的“适量修改”。
多态性：

多态性是继承的一个重要特性，允许同一方法在不同类的对象中有不同的行为。通过重写基类的方法，派生类可以提供自己的实现。
