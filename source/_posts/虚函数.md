允许我们在子类中重写方法。例如，我们有两个class，A和B，B是A派生出来的，也就是B是A的子类，如果在A类中创建一个方法，标记为virtual，我们可以选择在B类中重写那个方法，让它做其他的事情。
## 官方一点：
虚函数（Virtual Function）是C++中实现多态（Polymorphism）机制的关键特性之一。它允许派生类（Derived Class）重写基类（Base Class）中的函数，从而实现动态绑定（Dynamic Binding）或运行时多态（Run-time Polymorphism）。

虚函数是在基类中使用virtual关键字声明的成员函数，目的是允许派生类重写它。通过基类指针或引用调用虚函数时，会根据对象的实际类型（即运行时类型）调用相应的派生类版本的函数，而不是基类版本的函数。

使用虚函数时，程序不一定必须使用指针，但在实践中，通过指针或引用来实现多态是最常见的方式。这是因为虚函数的多态特性需要在运行时根据对象的实际类型来决定调用哪个函数实现，而这通常通过指针或引用来完成。
最常用的就是指针和引用。
```CPP
#include <iostream>
#include <cstring>
class Entity
{
public:
	std::string GetName() { return "Entity"; }
};

class Player : public Entity
{
private:
	std::string m_Name;
public:
	Player(const std::string&name)
		:m_Name(name){}        //':'是成员初始化列表，前面的const 是表示不可修改，string表示类型
	std::string GetName(){ return m_Name;  }
};
void PrintName(Entity *entity)
{
	std::cout << entity->GetName()<< std::endl;
}
int main()
{
	Entity *e=new Entity();
	PrintName(e);
	Player* p = new Player("Xavier");
	PrintName(p);
	Entity* entity = p;
	PrintName(entity);
	
}
```
此时结果应该全部都是Entity，可明显能看到p和entity是Player类里的，这个指向就很不明确，所以用虚函数可以重构原函数。

## 错误？
通常声明函数时，我们的方法通常在类内部（起作用），然后当要调用方法的时候，会调用属于该类型的方法。
我们的PrintName函数，参数为Entity，当调用该函数的时候，如果参数是Entity，就在Entity类里面寻找，但是这不是我们的本意。希望编译器能意识到，传的Entity，实际上是Player。
所以虚函数起作用了。
虚函数常常通过vtable来实现编译，Vtable包含基类中所有虚函数的映射，这样可以在他运行时，将他们映射到正确的override函数， 

正确代码
```CPP
#include <iostream>
#include <cstring>

class Entity
{
public:
	virtual std::string GetName() { return "Entity"; }
};

class Player : public Entity
{
private:
	std::string m_Name;
public:
	Player(const std::string&name)
		:m_Name(name){}
	std::string GetName() override { return m_Name;  }
};
void PrintName(Entity *entity)
{
	std::cout << entity->GetName()<< std::endl;
}
int main()
{
	Entity *e=new Entity();
	PrintName(e);
	Player* p = new Player("Xavier");
	PrintName(p);
	Entity* entity = p;
	PrintName(entity);
}

```
# 开销
虚函数会被并不是免费（无额外开销）的，有两种与虚函数相关的运行成本，
1.额外的内存来存储vtable，这样就可以分配到正确的函数。包括基类中要有一个成员指针，指向vtable。
2.每次调用虚函数的时候，我们需要遍历这个表，来确定要映射到哪个函数，这是额外的性能损失。
但是，其实没有非常大的影响（嵌入式可能会有一点），可用好用。
